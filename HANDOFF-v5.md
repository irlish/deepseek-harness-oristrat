## What shipped

1. **Codex-style thinking-level slider (F1).** The composer model menu's root pane replaces the effort drill-in with an animated stop slider (`ui-model-selection/src/client/EffortSlider.tsx`): one stop per adapter-advertised level (低/中/高/极高 for the oristrat roster), filled track, gliding knob, hollow knob plus `跟随提供商默认` caption while unset. Pointer drag (window-level pointermove/pointerup, refs against stale closures) and keyboard (arrows/Home/End with stopPropagation) commit through the unchanged `directory.select` path; a successful commit closes the menu. `apps/desktop/seed/settings.yaml` anchors `reasoningEfforts {low,medium,high,xhigh}` for all ten glm models plus route `compat.thinkingFormat: openai`; `settings-thinking-migration.ts` applies the same facts idempotently to an existing `~/.oristrat/settings.yaml` at startup, preserving an explicit `false`.
2. **DashScope WebSearch MCP (F2).** `mcp-client` `StreamableHttpConfig` gains `authorizationEnv`: a credential-ref resolved through the credentials service on every connection attempt and merged as `Authorization: Bearer <value>`; missing credential or missing credentials service fails loud at strict startup. The desktop-host patch mounts `dashscope-websearch` (streamable-http, `https://dashscope.aliyuncs.com/api/v1/mcps/WebSearch/mcp`, `failOnStartupError: false`); tools surface as `mcp__dashscope-websearch__bailian_web_search`. The key lives ONLY in `~/.oristrat/.env` as `DASHSCOPE_API_KEY` (chmod 600, never committed); config carries the reference, never the secret.
3. **Repo-environment panel (F3).** New `packages/api/gui-repo` Remote BFF (gui-terminal template): one read-only `status` verb runs local git (`rev-parse --show-toplevel`, `abbrev-ref HEAD` with unborn/detached fallbacks, `rev-list --left-right --count @{upstream}...HEAD`, `diff --numstat HEAD`, `ls-files --others --exclude-standard`, `remote -v`) through `ctx.subprocess` under an 8s bound and 1MB caps; failures degrade to omitted fields, non-repos answer `repo: false`. New `packages/client/ui-repo-panel` registers the `repo` right-sidebar tab: branch + ahead/behind, `+X -Y · N 个文件`, local host, remote sources; 4s polling, manual refresh, NO commit/push by product decision.
4. **Embedded browser (F4).** `apps/desktop/src/browser-view.ts` owns one `WebContentsView` per application window: persistent `persist:dsh-embedded-browser` partition, denied window opens (http(s) targets load in-view), http(s)-only navigation, state pushes on every navigation event; renderer bounds pass `sanitizeBounds` (finite, rounded, clamped). `preload-app.ts` exposes a `browser` face to the `dsh-app://app` document only; new `DESKTOP_IPC.browser*` channels are gated by `assertDesktopSender(event, ['app'])`. New `packages/client/ui-browser-panel` registers the `browser` right-sidebar tab: toolbar (back/forward/reload, address bar normalized to http(s)) above a measured surface; ResizeObserver + capture-phase scroll + window resize re-push bounds; unmount closes the view; plain web hosts get a desktop-only notice.
5. **Gate normalization.** `tsconfig.base.json` paths mappings for every fork-introduced bundle row (gui-terminal, gui-repo, ui-terminal-panel, ui-repo-panel, ui-browser-panel, oristrat-msce-norms, msce-gate) turned `verify-cordis-config` green (143 configs). New/fork manifests normalized (MIT license, matching cordis peer+dev, inject-list devDeps, `publishConfig.access`, repository directory, exact files, and gui-repo's missing `zod` runtime dependency — its generated `lib/typert.host.js` imports zod, which source-launch specs resolved through hoisting but the built-lib web e2e ladder could not). All seven fork-era package README pairs (including the two fork packages with no README at all) rewritten to the full package-reference skeleton with gate-shaped Model Experience sections; README invariant-reason sentences added; translation-pairing records refreshed including two pre-existing committed drifts (ui-conversation README, work-mode Agent Note) re-recorded as shipped.
